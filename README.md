# 🌐 WebAura — Website Development Agency (React + Vite + Tailwind)

A modern, high-performance, and SEO-friendly **Website Development Agency** website built using **React, TypeScript, Vite, Tailwind CSS**, and clean modular components.

## 🧠 Project Overview

WebAura is a fully responsive agency website built to deliver:

* Strong **brand identity**
* Modern **UI/UX design**
* Fast performance using **Vite**
* Mobile-first and SEO-ready pages
* Scalable, clean component architecture

## 🛠️ Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/agency-website.git
cd agency-website
```

### 2️⃣ Install dependencies

```bash
npm install
```

### 3️⃣ Start development server

```bash
npm run dev
```

### 4️⃣ Build for production

```bash
npm run build
```

### 5️⃣ Preview the build

```bash
npm run preview
```
